# 任务设计说明

## 1. 项目目标

本项目在 STM32F103C8T6 上使用 FreeRTOS 实现直流减速电机的闭环调速，重点练习：

- FreeRTOS 任务创建
- 任务优先级划分
- 固定周期任务调度
- 任务间数据共享
- 编码器测速和 PID 控制

## 2. 任务划分

| 任务 | 函数 | 周期 | 优先级 | 栈大小 | 主要工作 |
|---|---|---|---|---|---|
| 电机控制任务 | `TaskMotor` | 10 ms | 4 | 256 字 | 读取编码器、计算 PID、输出 PWM |
| 正弦目标任务 | `TaskSin` | 20 ms | 3 | 192 字 | 生成正弦目标转速 |
| 串口上传任务 | `TaskVofa` | 50 ms | 2 | 256 字 | 通过 USART1 上传波形数据 |

三个任务在 `App_Init()` 中通过 `xTaskCreate()` 创建，创建失败时调用 `Error_Handler()`。

## 3. 优先级设计

优先级数值越大，FreeRTOS 中任务优先级越高。

- **电机控制任务优先级 4**：周期最短，负责闭环控制，必须优先保证实时性。
- **正弦目标任务优先级 3**：周期 20 ms，只负责生成目标值，实时性要求低于电机控制。
- **串口上传任务优先级 2**：周期 50 ms，串口发送耗时较长，放在最低优先级，避免影响控制任务。

这样的划分可以保证电机控制任务按 10 ms 周期稳定运行，串口打印不会阻塞控制循环。

## 4. 调度方式

三个任务都使用 `vTaskDelayUntil()` 实现固定周期调度，而不是使用 `vTaskDelay()`。

`vTaskDelayUntil()` 以“上一次唤醒时间”为基准，可以减少任务执行时间波动带来的周期漂移，适合周期性的控制任务。

## 5. 数据流

```text
TaskSin（20 ms）
    │ 写入 g_target_rpm
    ▼
TaskMotor（10 ms）
    │ 读取 g_target_rpm
    │ 编码器测速得到 g_actual_rpm
    │ PID 计算得到 g_out_duty
    ▼
TaskVofa（50 ms）
    │ 读取 g_target_rpm、g_actual_rpm、g_out_duty
    ▼
USART1 → VoFA+ JustFloat
```

`g_target_rpm`、`g_actual_rpm`、`g_out_duty` 使用 `volatile float` 定义。当前三个变量都是 32 位浮点数，在 Cortex-M3 上按 32 位访问，单个变量的读写不会被打断；后续如果需要传输多个相关变量，建议增加队列或临界区保护。

## 6. 关键参数

| 参数 | 数值 |
|---|---|
| 电机控制周期 | 10 ms |
| 正弦目标周期 | 20 ms |
| 串口上传周期 | 50 ms |
| 正弦目标中心值 | 180 rpm |
| 正弦目标幅值 | 70 rpm |
| 正弦频率 | 0.2 Hz |
| 编码器线数 | 11 |
| 编码器倍频 | 4 |
| 减速比 | 18 |
| PWM 最大占空比 | 1000 |
| PID 参数 | Kp = 15.0，Ki = 45.0，Kd = 0.0 |
| 串口波特率 | 115200 |

## 7. 验证方法

1. 使用 Keil MDK 打开 `MDK-ARM/xiaozurenwu2.uvprojx`。
2. 点击 **Rebuild**，确认工程编译通过。
3. 连接 ST-Link，下载程序到 STM32F103C8T6。
4. 将 USART1 连接到 USB 转串口模块，波特率设置为 115200。
5. 打开 VoFA+，选择 JustFloat 协议，添加 3 个通道。
6. 给电机供电，观察以下现象：
   - 目标转速曲线应为 180 ± 70 rpm 的正弦波。
   - 实际转速应跟随目标转速变化。
   - PID 输出应随转速误差变化。
   - 串口数据刷新应保持稳定，不应明显阻塞电机控制。

## 8. 注意事项

- 电机和开发板必须共地。
- 电机供电与 STM32 供电要符合模块要求，避免驱动电流倒灌。
- 首次测试建议降低目标转速或断开电机，先确认编码器方向和 PWM 输出正常。
- 如果实际转速方向与目标相反，可调整 `MOTOR_DIR_INVERT` 或电机接线。
- 如果转速波动较大，先检查编码器计数方向、减速比和采样周期，再调整 PID 参数。
